使用方法

进入 CF 端游「设置 → 控制 → 鼠标灵敏度」，按所选模式勾选或取消“统一灵敏度”，录入鼠标移动速度与狙击镜移动速度。先连续使用 3 局，每次只微调 ±1。

说明：这是纯网页端 CF 端游个人手感校准工具，不读取游戏进程，也不能修改 Windows 或游戏设置。分辨率用于归一化测试结果；若选择手动修改，请先在 Windows「设置 → 系统 → 屏幕 → 显示器分辨率」完成修改，再回到网页重新检测。生成值是端游 1–100 整数建议值，并非官方推荐。
