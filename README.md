# 穿越火线灵敏度测试调试助手

一套纯 HTML、CSS、JavaScript 实现的 CF 端游 / CF 手游灵敏度测试与推荐工具。无需安装依赖，无需服务器，直接使用浏览器打开对应 HTML 文件即可运行。

> 本地浏览器运行，测试数据默认仅保存在当前浏览器缓存中，不上传。

## 在线入口

[打开 CF 灵敏度测试调试助手](https://xiaoxinailishi.github.io/cf-sensitivity-assistant/)

统一入口会识别当前浏览器属于桌面鼠标环境还是手机 / 平板触控环境，推荐相应版本；选择错误版本时会阻止进入并提示切换。

## 文件

- `CF灵敏度调试助手.html`：CF 端游鼠标灵敏度测试，仅允许在桌面浏览器运行。
- `CF手游灵敏度调试助手.html`：CF 手游触控灵敏度测试，仅允许在手机或平板触控浏览器运行。
- `index.html`：GitHub Pages 统一入口，负责设备识别、版本推荐与进入前校验。
- `DESIGN_SPEC.md`：完整设计方案、计算思路、验收标准，以及可直接交给 Codex 重新生成项目的提示词。

## 主要功能

### CF 端游版

- 鼠标 DPI、握法、主要打法和鼠标垫宽度档案。
- 自动检测当前浏览器可见分辨率，并修正浏览器边界造成的 1 像素误差。
- 分别选择测试分辨率和 CF 游戏内分辨率，推荐值根据二者换算。
- 每次重新打开页面后，如果测试分辨率与游戏内分辨率不同，首次开始任意一项测试都会先提示换算影响。
- 支持统一灵敏度与水平 / 垂直独立灵敏度。
- 三项鼠标测试：微调追踪、快速定位、狙击微调。
- 追踪无需点击；定位和狙击必须点击目标。
- 自定义测试时长、2 秒准备提示、全屏测试与疲劳修正。
- 多次测试保留最好成绩，每项可清除当前成绩但不删除历史。
- 生成 CF 端游可填写的“鼠标移动速度”和“狙击镜移动速度”建议。

### CF 手游版

- 二指 / 三指 / 四指以上、持机方式、主要打法、屏幕尺寸和触控采样率档案。
- 三项真实触控测试：按住滑动追踪、点按快速定位、点按狙击微调。
- 不使用电脑鼠标或模拟器数据冒充手机触控结果。
- 生成转向、开火、狙击一倍和非狙开镜四项手游灵敏度建议。
- 同步支持准备提示、自定义时长、疲劳修正、最好成绩和历史记录。

### 页面入口

- 两版页面左上角均提供固定显示的 GitHub 仓库入口，滚动页面时仍可看到。
- GitHub 入口旁提供“下载当前 HTML”按钮；端游版只下载端游文件，手游版只下载手游文件。
- 正式测试弹窗与设备阻断层位于仓库入口上方，不会干扰追踪、定位或狙击测试。

### 历史记录

- 使用 `localStorage` 持久化保存。
- 相同配置归入同一组合，自动读取该组合的历史最好成绩。
- 保存测试配置、各项成绩以及步枪、狙击、冲锋枪推荐方案。
- 支持 JSON 导出、导入和主动清空。
- 导入后自动匹配当前配置并恢复最好成绩与推荐值。

## 使用方法

1. 下载仓库或单独保存对应 HTML 文件。
2. 端游玩家在电脑浏览器打开 `CF灵敏度调试助手.html`。
3. 手游玩家把 `CF手游灵敏度调试助手.html` 放到手机可访问的位置，并使用手机或平板浏览器打开。
4. 按页面提示填写真实设备参数并依次完成三项测试。
5. 建议每项按默认时长测试多次，系统会保留当前配置下的最好成绩。
6. 把生成的值填写到游戏中，实际游玩 3 局后再按页面建议做小幅微调。

## 浏览器能力限制

- 纯网页无法读取鼠标驱动中的真实 DPI，必须由用户手动填写。
- 纯网页无法修改 Windows 或显卡控制面板的系统分辨率。
- 纯网页无法读取手机触控采样率，需查阅设备参数后手动填写。
- 浏览器全屏 API 在部分 iOS 浏览器中可能不可用，页面会继续测试但不会强制全屏。
- 推荐值是训练和初始校准建议，不是腾讯或穿越火线官方配置。
